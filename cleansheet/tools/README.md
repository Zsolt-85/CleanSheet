# Tools

Helper scripts for generating demo data and marketing assets. Run from `cleansheet/`.

| Script | Output |
|--------|--------|
| `gen_messy.py` | Small messy demo file → `tests/fixtures/input/messy_leads_demo.csv` |
| `gen_big.py` | Large stress-test file → `tests/fixtures/input/messy_leads_big.csv` |
| `make_graphic.py` | Before/after LinkedIn graphic → `assets/cleansheet_before_after.png` |
